# AI English Assistant 🚀


一个基于 Python + FastAPI + JavaScript 的英语学习辅助网站。


## 项目介绍

用户可以上传英语 Word 文档：

- 自动读取英文内容
- 自动生成中文翻译
- 点击英文单词查看释义


## 技术栈

Frontend:

- HTML
- CSS
- JavaScript


Backend:

- Python
- FastAPI
- python-docx


## 功能展示

### 上传英语文章

上传 Word 文件


### 英文解析

显示原文内容


### 单词查询

点击单词获取中文解释
